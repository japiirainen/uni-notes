\section{Ratkaisut}

\begin{exercise}
  \leavevmode\par
\begin{enumerate}[label=\alph*), nosep]
  \item Ilmaise itseisarvoepäyhtälön avulla: luvun \(x\) etäisyys luvusta
    \(\frac{1}{3}\) on korkeintaan \(3\).
  \item Mitkä luvut toteuttavat epäyhtälön \(\abs{4x - 6} < 1\)? Ilmaise
    vastaus kaksoisepäyhtälönä, välinä, ja sanallisesti etäisyyden avulla.
\end{enumerate}
\end{exercise}

\begin{solution}
\leavevmode\par
\begin{enumerate}[label=\alph*), nosep]
\item Haluttu ehto voidaan ilmaista itseisarvoepäyhtälön avulla muodossa
  \(\abs{x - \frac{1}{3}} \leq 3\).
\item Ilmaistaan ensin kaksoisepäyhtälönä käyttämällä itseisarvon määritelmää
  ja sieventämällä
  \begin{align*}
    \abs{4x - 6} < 1 &\iff -1 < 4x - 6 < 1 \\
    &\iff \frac{5}{4} < x < \frac{7}{4}.
  \end{align*}
  Sama tieto voidaan ilmaista välinä muodossa \(x \in \left(\frac{5}{4},
  \frac{7}{4}\right)\). Geometrinen tulkinta on kenties helpointa tehdä, jos
  muokkaamme alkuperäisen itseisarvoepäyhtälön muotoon
  \(\abs{x - \frac{6}{4}} < \frac{1}{4}\). Epäyhtälö toteuttaa siis ne luvut
  \(x\), joiden etäisyys luvusta \(\frac{6}{4}\) on pienempi kuin
  \(\frac{1}{4}\). Luku \(\frac{6}{4}\) on välin
  \(\left(\frac{5}{4}, \frac{7}{4}\right)\) \emph{keskipiste}.
\end{enumerate}
\end{solution}

\begin{exercise}
Ratkaise epäyhtälö \(\abs{2x - 1} < 3\) kahdella eri tavalla. Sovella
itseisarvon etäisyys tulkintaa ja vaihtoehtoisesti neliöi molemmat puolet
(ja perustele miksi näin saa tehdä).
\end{exercise}

\begin{solution}
Muokataan ensiksi epäyhtälö muotoon, josta geometrisen tulkinnan tekeminen
on helpompaa.
\[\abs{2x - 1} < 3 \iff 2\abs{x - \frac{1}{2}} < 3 \iff \abs{x -
\frac{1}{2}} < \frac{3}{2}.\]
Nyt, \(\abs{x - \frac{1}{2}}\) on pisteiden \(x\) ja \(\frac{1}{2}\) välinen
etäisyys lukusuoralla. Täten epäyhtälön toteuttavat kaikki \(x \in \RR\), joiden
etäisyys luvusta \(\frac{1}{2}\) on pienempi kuin \(\frac{3}{2}\). Näin ollen
\[\frac{1}{2} - \frac{3}{2} < x < \frac{1}{2} + \frac{3}{2},\]
eli \(x \in (-1, 2)\).

Ratkaistaan \(\abs{2x - 1} < 3\) neliöimällä molemmat puolet. Perustellaan
ensiksi kyseisen ratkaisutavan oikeellisuus.

Koska \(\abs{2x - 1}\ \geq 0\) ja \(3 \geq 0\), epäyhtälön molemmat puolet
ovat ei-negatiivisia. Funktion \(x \mapsto x^2\) on aidosti kasvava välillä
\([0, \infty)\), joten molempien puolien neliöinti säilyttää epäyhtälön suunnan.
Siis
\begin{equation}\label{squaring:valid}
\abs{2x - 1} < 3 \iff (2x - 1)^2 < 9.
\end{equation}

Ratkaisumenetelmä on nyt perusteltu, joten voimme siirtyä itse ratkaisun pariin.
Sieventämällä epäyhtälöä (\ref{squaring:valid}) saadaan
\begin{align*}
(2x - 1)^2 < 9 &\iff 4x^2 - 4x - 8 < 0 \\
&\iff x^2 - x - 2 < 0.
\end{align*}
Tekijöihin jakamalla saadaan
\[x^2 - x - 2 = (x + 1)(x - 2).\]
Joten
\[x^2 - x - 2 < 0 \iff (x + 1)(x - 2) < 0.\]
Kahden reaaliluvun tulo on negatiivinen jos ja vain jos toinen kerrottavista
luvuista on positiivinen ja toinen negatiivinen. Joten on oltava
\[x + 1 > 0, \qquad x - 2 < 0,\]
tai
\[x + 1 < 0, \qquad x - 2 > 0.\]
Ensimmäisestä saadaan
\begin{equation*}
\begin{cases}
  x + 1 &> 0 \\
  x - 2 &< 0
\end{cases}
\iff
\begin{cases}
  x &> -1 \\
  x &< 2
\end{cases}
\iff -1 < x < 2.
\end{equation*}
Toisesta saadaan
\begin{equation*}
\begin{cases}
  x + 1 &< 0 \\
  x - 2 &> 0
\end{cases}
\iff
\begin{cases}
  x &< -1 \\
  x &> 2
\end{cases}
\end{equation*}
mikä on mahdotonta, sillä se edellyttäisi samanaikaisesti
\(x < -1\) ja \(x > 2\). Näin ollen \(x^2 - x - 2 < 0 \iff x \in (-1, 2)\).
Siis myös alkuperäisen epäyhtälön \(\abs{2x - 1} < 3\) ratkaisu on
\(x \in (-1, 2)\).
\end{solution}
